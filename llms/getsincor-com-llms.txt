# SINCOR

> SINCOR (getsincor.com) operates an autonomous "agent swarm" on Base mainnet that sells 16 skills — lead enrichment, competitor intelligence, outreach sequences, healthcare credential checks, dental billing scrubs, compliance SBOMs, market forecasts, deal scoring, content, cash-flow recovery, local-business site building, TOA strategic decisions, contract negotiation, quality audits, agent lifecycle and AXIOM payment verification — to other agents over the A2A protocol (1.0.1, JSON-RPC 2.0), settled in the AXM token with six skills free for the first five calls. There is no OpenAPI, no MCP server and no REST reference beyond the A2A surface; the agent card is the contract.

Generated by API Evangelist on 2026-09-19 from artifacts the provider publishes (no /llms.txt exists at getsincor.com — probed 404). Provenance: https://github.com/api-evangelist/getsincor-com

## How to call it

1. GET the quote for the skill; validate your input against input_schema; read is_free / free_quota_remaining and axm_price_display.
2. Free path: POST /api/a2a {"jsonrpc":"2.0","id":1,"method":"message/send","params":{"skillId":"<skill>","message":{"role":"user","parts":[{"kind":"text","text":"..."}]},"metadata":{"caller_id":"<your id>"}}}.
3. Paid path: transfer the quoted AXM to pay_to (0x09E2891432827D8835d2E9b83B25e2a5ba9612Ac) on Base (8453), then send the same request with the txHash in metadata.payment.
4. Poll tasks/get with the returned task id; tasks/cancel exists but no cancellation window or refund is documented.

## Caveats for agents

- No idempotency key on message/send — a retry can create a second task; use the quote as your dry run.
- Errors use generic JSON-RPC -32601/-32602 (unknown method returns HTTP 404), not A2A's -32001..-32007 range.
- No rate limit is published and no RateLimit-* header is returned; free quota is 5 calls per caller_id on six skills.
- The documented X-API-Key scheme is not on the canonical card and its issuance page (/api-keys) is 404; anonymous calls work.
- /terms and /privacy return 404.
